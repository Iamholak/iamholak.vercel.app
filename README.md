
﻿# Holak Portfolio

Personal portfolio site for Holak, built with React and Vite.

## Stack

- React 18
- Vite 6
- Tailwind CSS 4
- Motion
- Lucide React

## Development

Install dependencies:

```bash
npm install
```

Start the local dev server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Project Notes

- This project is a Vite app, not a Next.js app.
- The app entry is [index.html](C:/Users/olawa/Programming/React/iamholak.vercel.app/index.html).
- Source code lives under [src](C:/Users/olawa/Programming/React/iamholak.vercel.app/src).

## Deployment

If you deploy this project on Vercel:

- Do not use the Next.js framework preset.
- Use the Vite preset if available, or use `Other`.
- Build command: `npm run build`
- Output directory: `dist`

The earlier `No Next.js version detected` error happens when the deployment platform incorrectly assumes this repo is a Next.js project.
